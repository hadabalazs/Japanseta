Lépés forráskód

Node.js 20 vagy újabb szükséges. Nincs telepítendő függőség.
Teszt: node --test engine.test.mjs
Build: node build.mjs

A Netlifyra feltölthető fájlok a dist mappába kerülnek.
A build új offline gyorsítótár-verziót számít.
A telepítési útmutató SVG ábrái a forrás részei, offline is működnek.
